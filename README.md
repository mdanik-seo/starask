# ReviewTent

Free Google review tools for local businesses: a review link generator, a QR code generator, a printable review card, review request templates, a Google Business Profile audit, a guide, and a checklist.

## How it's built

- Plain static site: HTML, CSS, and vanilla JavaScript. No framework, no build server.
- `build.py` writes every page from one template. Edit page copy in `PAGES` inside `build.py`, then run `python3 build.py`.
- `assets/tool.js` is the review tool (link, QR, card). `assets/qrcode.js` is qrcode-generator (MIT) by Kazuhiko Arase, bundled so the site needs no outside scripts.
- `sitemap.xml` and `robots.txt` are regenerated by `build.py`.

## Business name search and profile audit

`assets/places.js` handles business search and profile lookups for the review tool and the audit (`assets/audit.js`).

`assets/config.js` holds `mapsApiKey`. Leave it empty and the tool asks for a Place ID. Add a Google Maps Platform browser key (Maps JavaScript API and Places API (New) enabled, restricted to the site's domain) and the tool shows a "Find your business" search instead. The audit page shows a "see a sample audit" link until a key is set.

Add `?demo=1` to any page URL to try search and the audit with made-up sample businesses. Demo mode needs no key and costs nothing.

Google costs: search uses Autocomplete requests (10,000 free per month). Each audit is one Place Details call with Enterprise and Atmosphere fields (about 1,000 free per month, then billed per 1,000). Set quotas and a budget alert in Google Cloud.

## Hosting

Any static host works (GitHub Pages, Cloudflare Pages). All links are relative, so the site also works from a sub-path.
